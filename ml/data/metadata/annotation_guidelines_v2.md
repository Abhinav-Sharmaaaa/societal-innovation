# Annotation Guidelines V2

Use exactly one primary category.
Secondary categories are optional genuine cross-domain labels.
Severity and urgency are independent.
Innovation is TRUE only when routine maintenance, repair, staffing, procurement, administration, or standard service delivery is insufficient.
Routing is MUNICIPALITY, GOVERNMENT, INNOVATION, or HUMAN_REVIEW.
Synthetic IDs and generation markers belong only in metadata.
Synthetic numeric values and workflow outcomes are scenario annotations, not historical facts.
